# Amazon_PowerBI
📊 **Project Showcase: Amazon Prime TV Shows & Movies Analysis using Power BI**

I’m excited to share my latest **Data Analytics project — Amazon Prime TV Shows & Movies Dashboard**, built using Power BI.

The objective of this project was to analyze Amazon Prime's content catalog and create an interactive dashboard that provides meaningful insights into movies and TV shows.

🔍 **Key Analysis:**
• Total Movies and TV Shows
• Content distribution by Genre
• Movies vs TV Shows comparison
• Content trends by Release Year
• Ratings and content classification
• Country-wise content distribution
• Genre-wise content analysis
• Year-wise growth of content

📈 **Power BI Dashboard Features:**
• Interactive filters and slicers
• KPI cards
• Genre analysis
• Time-series visualizations
• Country-wise analysis
• Interactive charts and tables
• User-friendly dashboard design

🛠️ **Tools & Technologies:**
Power BI | Power Query | DAX | Excel | Data Cleaning | Data Visualization

💡 **What I learned:**
This project helped me improve my skills in **data cleaning, DAX calculations, data modeling, visualization, and business storytelling** while working with a real-world style dataset.

I’m continuing to build practical projects to strengthen my **Data Analytics and Business Intelligence** skills.
